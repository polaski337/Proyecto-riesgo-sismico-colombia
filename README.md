# Dashboard de Riesgo y Exposición Sísmica en Colombia

Dashboard interactivo desarrollado en Streamlit para visualizar sismicidad histórica, amenaza sísmica e infraestructura potencialmente expuesta en Colombia.

## Contenido

- Mapa interactivo de eventos sísmicos
- Filtros por departamento, año, magnitud y nivel de amenaza
- Indicadores principales
- Gráficos de eventos por año, magnitud y departamento
- Análisis exploratorio de exposición sísmica
- Conclusiones técnicas para portafolio profesional

## Fuentes de datos

- Servicio Geológico Colombiano - SGC
- DANE
- SISPRO / Ministerio de Salud
- INVIAS

## Nota metodológica

Este dashboard representa amenaza y exposición potencial. No corresponde a un modelo oficial de riesgo sísmico.
